# Public Documentation

**Classification:** Public
**Owner:** DARP CLI maintainers
**Source:** Created for the DARP CLI project; publication rights for included third-party material must be confirmed before release.
**Audience:** DARP CLI users and contributors

This directory is reserved for documentation approved for public distribution. Internal planning, roadmaps, project context, specifications, and ADRs belong in the private `darp-cli-specs` repository.

- [`user-guide/`](user-guide/README.md): public usage guidance.
- [`reference/`](reference/README.md): public commands and file-format contracts.
- [`specifications/`](specifications/README.md): approved public specifications only.
